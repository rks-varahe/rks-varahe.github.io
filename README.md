# Varahe Analytics — National Communications Handbook (Public Mirror)

Public mirror of the National Communications interactive handbook, hosted on GitHub Pages.

Live URL: https://rks-varahe.github.io

The protected version (Netlify Identity gated) lives at https://github.com/rks-varahe/varahe-ncc-handbook.

## Pages
- `index.html` — landing
- `team.html?id=<team-id>` — generic team page
- `resources.html` — sample decks library (links to Google Drive)

## Tech
Pure static — HTML, CSS, JS. No build step. Open `index.html` in any browser.

- `data.js` — all team content, glossary, coordination edges, category tags
- `india-shapes.js` — Survey-of-India boundary paths (CC0)
- `app.js` — renderers
- `styles.css` — theme + responsive layout
